계측 데이터 처리 · 3D 그래프

샘플링 주기·시작 시각·시간 형식이 다른 계측기 파일을 한 시간축으로 맞춥니다. 시작 시각으로 먼저 맞추고, 남은 어긋남은 기준 신호와의 교차상관으로 추정해 보정합니다. 전처리·이상치 표시·엑셀 내보내기를 하고, 독립변수 2개·종속변수 1개로 돌려 보는 3D 그래프를 그립니다.

1. 계측 파일을 올리세요

CSV·TXT·엑셀(.xlsx) 여러 개를 한 번에 올릴 수 있습니다. 엑셀은 시트마다 계측기 하나로 읽습니다. 시간 열(날짜+시각, 시각만, 경과 초·ms)과 머리말의 시작 시각·샘플링 주기를 스스로 찾습니다.

예제는 가상 지게차의 응력(50 Hz)·가속도(200 Hz) 계측 2종입니다. 예제 데이터는 실제 사내 데이터가 아닙니다.

2. 시간 동기화

기준 파일의 시작을 0초로 둡니다. 다른 파일은 시작 시각 차이만큼 옮긴 뒤, 기준 신호와 같은 사건(충격·시동)이 겹치도록 지연을 추정해 한 번 더 옮깁니다.

지연 보정 전후 (기준 신호 봉우리 둘레)

3. 전처리

원래 샘플에서 처리한 뒤 공통 시간축으로 옮깁니다. 순서: 이상치 찾기 → (고르면) 보간으로 바꾸기 → 배율·오프셋 → 영점 → 이동평균 → 저역통과. 저역통과는 앞뒤로 두 번 걸어 시간 지연이 생기지 않습니다.

이상치 기준은 「앞뒤 점에서 혼자 튄 정도」가 보통 퍼짐의 몇 배인가입니다. 0 이면 찾지 않습니다.

4. 동기화 결과

빨간 점은 이상치로 표시된 곳입니다. 보간값 표시가 있는 채널은 원래 샘플 사이를 선형 보간으로 채운 값입니다.

요약 문장

숫자에서 규칙으로 만든 문장입니다. 보고서에 붙여 쓰세요.


  

    AI 로 문장 다듬기 (선택)
    
키가 없어도 위 요약과 모든 계산은 그대로 됩니다. 키는 이 브라우저에만 저장됩니다.
       AI 에는 요약 문장만 보내고 계측 원데이터는 보내지 않습니다.
